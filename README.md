# 👔 Digital Closet (PWA)
Digital Closet is a simple website that helps users manage their clothes on their phones.
Users can add clothes, upload photos, create their own clothing groups, and record how many times they wear each item. They can also sort clothes by season.
The app saves data in the browser, so it does not need a server or database.
# 🌟 Features
- **Custom Clothing Groups**: Users can add, edit, and delete clothing groups. The app also has basic groups, such as tops, pants, shorts/skirts, and jackets.
- **Season Filters**: Users can view clothes by spring, summer, autumn, or winter.
- **Wear Count**: Users can record how many times they wear each item.
- **Photo Upload**: Users can take photos or choose photos from their devices. The app makes photos smaller before saving them to save space.
- **Save Drafts**: When users add or edit clothes, the app saves their drafts. They can continue editing or delete the drafts when they return.
- **Add to Home Screen**: Users can add the website to their phone’s home screen and open it like an app.
- **No Server Needed**: The app saves data in the browser using localStorage. Users do not need an account, and their data is not sent to a server.
# 🚀 How to Use
1. Open the website using the link below.
2. Add a new clothing item.
3. Enter the item’s name and choose a season and a clothing group.
4. Upload a photo if you want.
5. Save the item to add it to your closet.
6. Use the filters to find clothes by season or group.
7. Update the wear count when you wear an item.
8. Edit or delete clothing items whenever you need to.
Website: **(https://otvtovo.github.io/DigitalCloset/)**
# 📱 Use on Your Phone
You can add the website to your phone’s home screen for easy access.
* iPhone: Open the website in Safari, tap the Share button, and choose “Add to Home Screen.”
# ⚠️ Important Notes
* Your clothing data is saved in your browser using localStorage.
* Your data may be lost if you clear your browser data or switch to another device.
* This app does not have an online account or cloud backup.
🛠️ Tools Used
- **HTML5**: Builds the basic structure of the website.
- **CSS3**: Controls the design, layout, and animations.
- **JavaScript (ES6+)**: Makes the app work, saves data, handles photos, and responds to user actions.
